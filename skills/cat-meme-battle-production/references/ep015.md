# 第 15 期实例与代码入口

这是已产出实例，参数供参考，不是未来每期强制模板。

| 项目 | 阿米嘎蒂朵猫猫 | 九九成稀罕物 |
| --- | --- | --- |
| 平时 | 静态图移动 | 静态图移动 |
| 触发 | timer，首轮战斗 1 秒后 | timer，首轮战斗 1 秒后 |
| 片段 | 5 秒，原速 | 源前 6 秒，音画 1.2 倍，输出 5 秒 |
| 演出结束后冷却 | 2.5 秒 | 2.5 秒 |
| 启动间隔 | 约 7.5 秒 | 约 7.5 秒 |
| 实体 | 每轮 1、2、3、4…个分身 | 固定两枚蛋弹 |
| 发射时刻 | 在片段 1.2–2.4 秒之间均匀依次发射 | 片段 1.4 秒同时发射 |
| 固定命中伤害 | 每个分身 50 | 每枚蛋 60 |
| 可见性修正 | 奇数中间分身错开本体 | 开头 7 个透明帧用首个有效姿势补齐 |

本期 HP 均 420、atk/defense 均 0，整期约 35.3 秒；该固定状态白猫剩 70 HP 获胜。剧情悬念来自清楚可见的分身成长和实际命中，不是随机暴击。

```yaml
memeSkill:
  name: 猫猫分身舞
  trigger: timer
  initialCooldown: 1
  duration: 5
  every: 2.5
  hitAt: 0.35
  damage: 50
  range: 300
  framePrefix: memes/amigatito/
  frameCount: 75
  fps: 15
  sound: meme_amigatito
  effect: { kind: clones, cloneGrowth: true, launchTimes: [1.2, 2.4], speed: 580 }
```

`hitAt/range` 是当前 schema 的基础字段；存在 `effect` 时实际伤害走弹丸几何碰撞，不在 `hitAt` 直接扣血。普通分身的 `launchTimes` 是两个递增发射时刻；成长分身把它作为首次与末次的发射窗口。双蛋配置 `kind: eggs`、弹丸 sprite、相同的两个发射时刻。

关键入口：

- `scripts/prepare_cat_meme.ts`：源片段、绿幕 alpha、音画倍速、空帧保持和来源记录。当前 specs 仅有这两只猫，制作新一期须适配新输入与参数。
- `public/episodes/ep015-cat-meme.yaml`：本期参数；`public/scripts/cat-meme.lua`：消费技能/攻击事件的演出音效。
- `src/core/types.ts` / `loader.ts`：字段与校验；`src/core/sim.ts`：定时触发、次数成长、实体与固定伤害。
- `src/core/memeMotion.ts`：绘制与碰撞共用曲线；`src/render/memeFrames.ts`：按模拟时间选择帧。
- `src/render/draw.ts` / `fx.ts`：静态/动态切换、分身/双蛋、CD 与数量 HUD。
- `src/audio/browserAudio.ts` / `mixer.ts`：浏览器同步与离线混音；`src/tts/volcV3.ts`：豆包 2.0 解说。
- `scripts/check_meme_battle.ts`：本期固定结果、成长、并排、时间预算等；制作其他期应新增或适配检查，不能把第 15 期预期胜负直接用于其他角色。
- `scripts/prepare_bili_ep015.ts`：本期专用封面与 metadata；复用时修改文件路径、标题、角色、布局和简介，不直接重复投第 15 期。
